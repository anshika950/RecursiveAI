📊 Complete API Flow

1
Register: POST /auth/register → Create user account → Return JWT token
2
Login: POST /auth/login → Verify credentials → Return new JWT token
3
Authorize: Store token in localStorage → Include in Authorization header
4
Verify Token: Server extracts token → Verify signature → Check expiration
5
Generate: POST /model/generate (with token) → Call AI model → Validate response
6
Response: Return Pydantic v2 validated JSON → Display to user

🔒 JWT Security Flow

User Registration
         ↓
Create credentials
         ↓
Hash password (Argon2)
         ↓
Store in SQLite DB
         ↓
Generate JWT token
         ↓
Return to client
         ↓
Client stores token (localStorage)
         ↓
Send in requests: Authorization: Bearer TOKEN
         ↓
Server verifies signature + expiration
         ↓
Extract username from token
         ↓
Allow access to protected endpoints

Headers: Authorization: Bearer TOKEN

📝 Raw API Requests

1. Register User

POST /auth/register HTTP/1.1
Host: localhost:8000
Content-Type: application/json

{
  "username": "demouser",
  "email": "demo@example.com",
  "password": "DemoPass123"
}

Response (200):
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}

2. Login User

POST /auth/login HTTP/1.1
Host: localhost:8000
Content-Type: application/json

{
  "username": "demouser",
  "password": "DemoPass123"
}

Response (200):
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}

3. Generate Text (Protected)

POST /model/generate HTTP/1.1
Host: localhost:8000
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

{
  "prompt": "What is machine learning?",
  "max_tokens": 100,
  "temperature": 0.7
}

Response (200):
{
  "generated_text": "Machine learning is...",
  "model": "mistral",
  "tokens_generated": 45
}

4. Check Model Status (Protected)

GET /model/status HTTP/1.1
Host: localhost:8000
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Response (200):
{
  "model": "mistral",
  "status": "online",
  "available": true
}

5. Health Check (Public)

GET /health HTTP/1.1
Host: localhost:8000

Response (200):
{
  "status": "healthy"
}

6. Request Without Token (Error)

POST /model/generate HTTP/1.1
Host: localhost:8000
Content-Type: application/json

{
  "prompt": "test"
}

Response (401):
{
  "detail": "Not authenticated"
}

cURL Examples

# Register
curl -X POST http://localhost:8000/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"demouser","email":"demo@example.com","password":"DemoPass123"}'

# Login
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demouser","password":"DemoPass123"}'

# Generate (replace TOKEN with actual token)
curl -X POST http://localhost:8000/model/generate \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"What is AI?","max_tokens":100,"temperature":0.7}'

# Check Status
curl -X GET http://localhost:8000/model/status \
  -H "Authorization: Bearer TOKEN"
