4

📍 Available Endpoints:

POST/auth/register - Register new user
POST/auth/login - Get JWT token
POST/model/generate - Generate text (⚠️ requires token)
GET/model/status - Check model status (⚠️ requires token)
GET/health - Health check (no auth needed)

📝 Raw API Requests (for reference)

Register Request:

POST /auth/register
Content-Type: application/json

{
  "username": "testuser",
  "email": "test@example.com",
  "password": "testpass123"
}

Generate Text Request (with JWT):

POST /model/generate
Authorization: Bearer YOUR_TOKEN_HERE
Content-Type: application/json

{
  "prompt": "What is machine learning?",
  "max_tokens": 100,
  "temperature": 0.7
}
