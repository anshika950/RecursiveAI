✨ Requirements

  • Username: 3-50 characters
  • Email: Valid email format
  • Password: Minimum 8 characters
  • Password: Hashed with Argon2
  • JWT Token: Auto-generated
  • Token Expiry: 30 minutes
  • Database: SQLite persistence
  • Validation: Pydantic v2 strict

🔑 Sign In

ℹ️ About Login

  • Endpoint: POST /auth/login
  • No authentication required
  • Returns JWT access token
  • Token format: Bearer scheme
  • Credentials verified against DB
  • Password verified with hash
  • Cryptographically signed tokens
  • Use token in Authorization header

🏗️ System Architecture

⚡ FastAPI Framework Modern async web framework with auto-generated docs and high performance
✓ Pydantic v2 Strict runtime schema validation for requests and responses
🔐 JWT Auth HS256 signed tokens with expiry and user identity claims
💾 SQLAlchemy ORM Database models with SQLite for persistent data storage
🔒 Argon2 Hashing Memory-hard secure password hashing algorithm

📨 API Request Examples

Register Request
curl -X POST http://localhost:8000/auth/register \ -H "Content-Type: application/json" \ -d '{ "username": "john_doe", "email": "john@example.com", "password": "SecurePass123" }'
Generate Text Request
curl -X POST http://localhost:8000/model/generate \ -H "Authorization: Bearer YOUR_JWT_TOKEN" \ -H "Content-Type: application/json" \ -d '{ "prompt": "What is artificial intelligence?", "max_tokens": 100, "temperature": 0.7 }'
